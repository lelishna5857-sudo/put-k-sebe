# Путь к себе

Статический сайт на HTML, CSS и JavaScript. Откройте `index.html` через локальный сервер. Деплой: GitHub Pages из корня ветки `main`.

## Колода

36 карт в `script.js`, по шесть в каждом блоке. ID 1–36 стабильны. Файлы `images/card-NN.svg` — оригинальные геометрические иллюстрации в палитре сайта. Файлы `audio/card-NN.mp3` — отдельные 16-секундные инструментальные настрои без речевой озвучки. Для замены медиа сохраните имена файлов.

Карта дня сохраняется в `localStorage` браузера на текущую локальную дату. Расклад каждый раз выбирает три разные карты. Онлайн-аккаунтов и серверной синхронизации пока нет.

## Интеграции

В `script.js` заполните `CONFIG.vk`, `CONFIG.tg`, `CONFIG.vkchannel` после создания каналов и ботов. Пока пустые ссылки показаны неактивными. Для оплаты предусмотрено поле `CONFIG.checkout`, но тарифы пока информационные. Перед подключением оплаты нужен сервер: создавать заказ, проверять подпись уведомления провайдера, хранить статус доступа и применять ограничения на сервере. Нельзя доверять `localStorage` для платного доступа.

Для Telegram/VK используйте ID карты и поля из `CARDS` как единую схему контента. Токены ботов, платёжные ключи и подтверждение подписки должны находиться только на сервере. В текущем статическом сайте платёжных и бот-серверов нет.
